# 不确定下的决策（`decision-under-uncertainty`）

> 领域：通用。工作结构：`decision_tree`。

```yaml
id: decision-under-uncertainty
name: 不确定下的决策
workbench: decision_tree
recognize:
  surface_cues: ["要不要", "值不值得冒险"]
  structural_checks: ["情景和大致概率能列出"]
  discriminating_test: "概率完全说不清？是 → 改用稳健决策（最坏情况下也能接受的）"
```

**识别特征**：要现在选，结果取决于不确定的未来。

**方法步骤**：

1. 画决策树（选择 → 情景 → 结果）
2. 期望值加尾部风险
3. 信息价值：先花小钱获取信息是否值得
4. 可逆的先做，不可逆的慢做

**合适表示**：决策树。

**在原问题里怎么验证**：小试（probe）的真实结果；B 类结论写成预测，到期结算。

**适用假设**：情景和概率能列出。

**失效信号**：概率完全说不清。

**常见陷阱**：只看期望值，忽略尾部风险；把不可逆的决定当可逆的做。

**例子**：要不要换工作；要不要先小额试用再大额投入。
