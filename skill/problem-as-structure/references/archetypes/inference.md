# 推断与逆问题（`inference`）

> 领域：通用。工作结构：`generic_graph`。

```yaml
id: inference
name: 推断与逆问题
workbench: generic_graph
recognize:
  surface_cues: ["市场在定价什么", "为什么会这样"]
  structural_checks: ["生成过程大体知道"]
  discriminating_test: "多个参数组合能否解释同一观测？能 → 可辨识性差，补观测或给出一条曲线"
```

**识别特征**：看得到结果，要反推原因或参数。

**方法步骤**：

1. 写生成模型（参数 → 观测）
2. 反解；贝叶斯更新
3. 先查同类事件的历史基准率

**合适表示**：生成模型与参数表（暂用通用图，标准化待补）。

**在原问题里怎么验证**：用反解出的参数预测一个还没用过的观测，看是否对得上。

**适用假设**：生成过程大体知道。

**失效信号**：多个参数组合都能解释同一观测。

**常见陷阱**：只给一个点估计，忽略可辨识性。

**例子**：从股价反解市场隐含的增长与寿命。
