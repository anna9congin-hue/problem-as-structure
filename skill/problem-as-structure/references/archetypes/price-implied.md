# 从价格反解预期（`price-implied`）

> 领域：投资。工作结构：`argument_graph`。

```yaml
id: price-implied
name: 从价格反解预期
workbench: argument_graph
recognize:
  surface_cues: ["便宜还是贵", "市场在定价什么"]
  structural_checks: ["有可用的定价模型和价格"]
  discriminating_test: "是否有多个参数组合给出同一价格？有 → 给出一条曲线而不是一个点"
```

**识别特征**：想知道市场已经计入了什么。

**方法步骤**：

1. 写定价模型
2. 用当前价格反解隐含参数（增长、寿命、通胀）
3. 和自己的推演对比，预期差超过容错带才行动

**合适表示**：生成模型（暂用通用图）+ 论证图记录预期差论断。

**在原问题里怎么验证**：反解结果可复算（A 类）；预期差论断写成预测到期结算（B 类）。

**适用假设**：定价模型大体合理。

**失效信号**：可辨识性差。

**常见陷阱**：把模型的点估计当成真实价值。

**例子**：从股价反解 g–λ 等价格曲线；从通胀掉期反解通胀预期。
