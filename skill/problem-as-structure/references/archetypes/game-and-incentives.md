# 博弈与激励（`game-and-incentives`）

> 领域：通用。工作结构：`generic_graph`。

```yaml
id: game-and-incentives
name: 博弈与激励
workbench: generic_graph
recognize:
  surface_cues: ["他们为什么拒绝", "谈判"]
  structural_checks: ["对方的目标大致可推断"]
  discriminating_test: "对方有没有稳定的规则或激励？没有 → 只能小成本试"
```

**识别特征**：结果取决于其他人或机构怎么反应。

**方法步骤**：

1. 写参与方—目标—约束表
2. 找均衡
3. 设计让对方愿意配合的方案

**合适表示**：参与方表（暂用通用图，标准化待补）。

**在原问题里怎么验证**：按对方的规则提交一次小规模尝试，看反应。

**适用假设**：对方目标可推断。

**失效信号**：对方纯人为裁量。

**常见陷阱**：把对方的风控规则当成恶意。

**例子**：银行风控为什么拒绝；平台审核。
