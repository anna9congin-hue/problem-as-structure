# 优化与对偶（`optimization`）

> 领域：通用。工作结构：`candidate_tree`。

```yaml
id: optimization
name: 优化与对偶
workbench: candidate_tree
recognize:
  surface_cues: ["最划算", "最优"]
  structural_checks: ["目标和约束能写成数字或可比较的形式"]
  discriminating_test: "能写出目标函数吗？写不出或多个目标说不清权重 → 先问偏好，或列帕累托前沿"
```

**识别特征**：要"最好的"，有取舍；目标能量化。

**方法步骤**：

1. 找绑定约束（真正卡住结果的那条）与影子价格
2. 先放松求上界，再收紧

**合适表示**：目标函数 + 约束表（可用候选树记录可行方案，attrs 记数值）。

**在原问题里怎么验证**：代入原问题的真实数字重算；小规模时穷举对照。

**适用假设**：目标与约束可量化。

**失效信号**：目标彼此冲突且说不清权重。

**常见陷阱**：把软偏好当成硬约束，导致可行集为空。

**例子**：预算分配；仓位在压力预算下的配置。
