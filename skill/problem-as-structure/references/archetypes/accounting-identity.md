# 会计恒等式与守恒（`accounting-identity`）

> 领域：投资。工作结构：`argument_graph`。

```yaml
id: accounting-identity
name: 会计恒等式与守恒
workbench: argument_graph
recognize:
  surface_cues: ["数字对不上", "三表"]
  structural_checks: ["存在必然成立的恒等式（资产 = 负债 + 权益；三部门余额和为零）"]
  discriminating_test: "恒等式能否在这组数据上逐期检查？能 → 把它当验证器"
```

**识别特征**：有恒等关系约束的量：资产负债表、现金流、部门收支。

**方法步骤**：

1. 列出相关恒等式
2. 逐期检查；不平即停
3. 用恒等式框住其他推断的范围

**合适表示**：候选树或论证图（恒等式当验证器）。

**在原问题里怎么验证**：逐期计算恒等式残差（A 类验证器）。

**适用假设**：数据口径一致。

**失效信号**：口径不一致（合并范围、会计准则变化）。

**常见陷阱**：在不平的数据上继续推演。

**例子**：财报三表勾稽；国民经济三部门余额。
