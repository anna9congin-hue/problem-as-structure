# 因果识别（`causal-identification`）

> 领域：投资。工作结构：`generic_graph`。

```yaml
id: causal-identification
name: 因果识别
workbench: generic_graph
recognize:
  surface_cues: ["A 导致 B", "回测里的相关性"]
  structural_checks: ["能画出因果图，并能指出混杂、中介、碰撞变量"]
  discriminating_test: "样本是不是按结果筛选出来的？是 → 碰撞偏差，结论无效"
```

**识别特征**：要估计 X 对 Y 的因果效应，而不是相关。

**方法步骤**：

1. 画因果图
2. 后门调整（控制共同原因）
3. 有不可观测混杂时找前门中介或工具变量
4. 不在碰撞变量（共同结果）上做条件

**合适表示**：因果图（暂用通用图，标准化待补）。

**在原问题里怎么验证**：用留出期或外生冲击检验效应方向；写成预测到期结算。

**适用假设**：因果图大致正确。

**失效信号**：体制切换后效应消失（卢卡斯批判）。

**常见陷阱**：在明星股池里做回测（按结果筛选）。

**例子**：赤字对汇率的效应；信贷脉冲对需求的效应。
