# 诊断与故障定位（`diagnosis`）

> 领域：通用。工作结构：`candidate_tree`。

```yaml
id: diagnosis
name: 诊断与故障定位
workbench: candidate_tree
recognize:
  surface_cues: ["出问题了", "报错"]
  structural_checks: ["原因集合大致能列出", "检查结果可信"]
  discriminating_test: "能否一次检查排除一半原因？能 → 二分"
```

**识别特征**：有症状，要找出哪里坏了。

**方法步骤**：

1. 每一步选信息量最大的检查
2. 能二分就二分
3. 先排除便宜、常见的原因

**合适表示**：症状—原因二部图（候选树：每个原因一个候选）。

**在原问题里怎么验证**：在原问题里复现与修复后回归。

**适用假设**：原因集合大致能列出。

**失效信号**：多个原因同时作用 → 逐个隔离。

**常见陷阱**：没有复现就宣布修好。

**例子**：程序 bug；身份核验为什么失败。
