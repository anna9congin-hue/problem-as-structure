# 体制切换（`regime-switching`）

> 领域：投资。工作结构：`decision_tree`。

```yaml
id: regime-switching
name: 体制切换
workbench: decision_tree
recognize:
  surface_cues: ["这次不一样", "历史规律失效"]
  structural_checks: ["能写出区分体制的可观测指标"]
  discriminating_test: "参数在不同时期是否稳定？不稳定 → 按体制分段，或把当前母题的假设标为失效"
```

**识别特征**：同一关系在不同时期参数不同或方向相反。

**方法步骤**：

1. 先识别当前体制
2. 按体制分别估计
3. 体制切换时重审所有依赖旧参数的结论

**合适表示**：决策树（情景 = 体制）。

**在原问题里怎么验证**：体制指标的实际读数；依赖它的预测到期结算。

**适用假设**：体制可观测。

**失效信号**：体制只能事后识别。

**常见陷阱**：用全样本参数套当前体制。

**例子**：低债务期与高债务期的加息弹性。
