# 投资领域包

投资问题的核心决策大多是 B 类：结果要等很久才知道，而且对错里混着运气。所以这个领域包的重点是两件事：尽量把能拆的部分拆成有现成验证器的 A 类检查；把剩下的结论写成预测，事前登记、到期结算。

## 母题（文件在 `references/archetypes/`）

| 母题 | 文件 | 什么时候用 |
|---|---|---|
| 会计恒等式与守恒 | `accounting-identity.md` | 有资产负债表、现金流、部门收支等恒等关系时；把恒等式当验证器 |
| 因果识别 | `causal-identification.md` | 要说"A 导致 B"时；先查混杂、中介和碰撞偏差 |
| 体制切换 | `regime-switching.md` | 历史规律可能失效时；体制一变，重审依赖旧参数的结论 |
| 从价格反解预期 | `price-implied.md` | 判断贵还是便宜时；先问市场已经计入了什么 |

常和通用母题组合：不确定下的决策（仓位与时机）、优化与对偶（压力预算下的配置）、瓶颈与最小割（产业链卡点）、论证与证明（投资论点本身）。

## 现成的验证器

| 验证器 | 类别 | 检查什么 |
|---|---|---|
| 资产 = 负债 + 权益，逐期 | A | 财报数据是否自洽 |
| 现金流量表期末现金 = 资产负债表现金 | A | 三表勾稽 |
| 期初留存收益 + 净利润 − 分红 = 期末留存收益 | A | 利润结转 |
| DCF 终值占企业价值的比例 | A | 估值是否过度依赖远期假设（占比过高要标出） |
| 比率、增长率、估值公式重算 | A | 计算是否正确 |
| 持仓台账与券商对账单核对 | A | 账是否对得上 |
| 回测代码的已知答案测试、未来函数检查 | A | 回测是否按规格实现 |
| 回测结果本身 | 弱 B | 容易过拟合和多重检验，不能当成结论的证据 |
| 盈利预测、目标价、策略收益 | B | 写成预测：证伪条件、结算日、概率；到期 `pas settle` |
| 管理层质量、护城河、仓位与风险承受 | C | 判断与价值决定，归用户 |

## 预测怎么写

论证图里的一条论断加 `prediction`：

- `statement`：可观测的结果，例如"下季度毛利率不低于 45%"。
- `falsifier`：观察到什么就算错，例如"连续两个季度环比下滑超过 150 个基点"。
- `settle_by`：结算日。
- `p`：事前概率，用于统计 Brier 分数。
- 依赖某个事件（财报、审批）时写 `event`：日期，以及结果好、坏两种情况下各自怎么做。事件发生后只做判定，不重写理由。

## 注意事项

- 证据要记 `observed_at`。决策之后才知道的信息不能用来支持当时的决策（防前视偏差）；`pas` 会拦下这种写法。
- 不在按结果筛选出的样本上做因果判断（例如只看涨了 10 倍的股票）。
- 模型可能见过历史行情；用历史数据检验方法时，选模型训练截止日之后的区间，或把日期和标的匿名化。
- 这个 skill 不做账本、风控和下单；它产出的是经过检验的判断和可结算的预测。
